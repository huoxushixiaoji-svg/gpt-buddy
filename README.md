# GPT 小伙伴

“GPT 小伙伴”是一个无需构建、可直接加载到 Microsoft Edge 的 Manifest V3 扩展。它只在 `https://chatgpt.com/*` 运行，通过 Shadow DOM 注入角色挂件。v0.4.6 增加四边吸附与左右镜像；打开 ChatGPT 后会自动启动后台用量页定期读取。气泡在 5 小时额度与周额度之间切换，并直接显示页面的“X 小时 X 分钟后重置”“X 天 X 小时后重置”。周额度页从“使用限额重置”区域读取可用次数，在气泡中显示为“限额重置次数”。

## 安装

1. 解压 `gpt-buddy-edge.zip`。
2. 在 Microsoft Edge 地址栏打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择解压后、直接包含 `manifest.json` 的文件夹。
6. 打开或刷新 ChatGPT 页面，然后查看页面右下角的挂件。

也可以直接选择本源码目录进行开发加载。修改脚本后，在扩展管理页点击“重新加载”，再刷新 ChatGPT 页面。

## 使用

- 左键点击角色：在“5 小时额度”和“周额度”之间切换，立即重读当前可见用量区域，并请求后台用量页更新；角色同时短暂压扁并弹回。关闭动画或启用系统“减少动态效果”后仍可切换和读取。
- 拖动角色：靠近屏幕左、右、上、下边缘约 72 像素时会自动吸附。左侧会镜像人物与原图气泡轮廓，右侧恢复原朝向；吸附在上、下边时按所在左右半屏朝向内侧，气泡文字始终正向。位置和吸附边会保存在 `chrome.storage.local`，刷新和窗口缩放后仍沿着该边缘。
- 右键角色：打开挂件菜单。菜单包含重新读取、缩放、动画开关、隐藏和清除本地用量数据。
- 右键菜单中的“重新读取当前页面”：只重新扫描当前页面。后台页可从工具栏弹窗的“立即尝试更新”单独刷新。
- 工具栏图标：挂件隐藏后可从弹窗恢复显示，也可调整大小、切换动画或清除快照。

气泡一次显示当前选中窗口的余额与恢复信息，不设置内部滚动条；文字会按内容自动缩小至能放进气泡。页面明确给出相对时间时，气泡直接使用该页面文案，例如“4 小时 45 分钟后重置”，不改写为“约还剩”；这行和“限额重置次数”使用较小字体。页面给出完整日期和时区时，显示恢复时刻及倒计时。日期或时区不明确的绝对时间只保留原文，不猜测倒计时。顶部仅显示当前窗口名称，不显示操作提示。周额度页另外显示“限额重置次数”；没有可靠读数时显示“暂无数据”，不会把它当成额度余额，也不会把重置次数的到期时间当成额度恢复时间。未识别的普通用量项目不再进入挂件。来源与采集时间保留在内部数据中，不占用气泡。无数据时显示“暂无准确数据”；读取失败、离开来源页、超过 15 分钟或已过恢复时间时，保留历史值并把“待更新”放在气泡底部，不会自动恢复为 100%。

### 后台更新（实验性）

1. 安装或更新扩展后，打开或刷新 ChatGPT 页面；后台更新自动开启，无需手动先进入余额页面。工具栏弹窗可关闭或再次开启。
2. 扩展创建一个**非活动固定标签页**，打开 `https://chatgpt.com/settings/usage?tab=overview`。它在标签栏仅占一个图标，你可继续在原聊天页使用挂件。Edge 扩展没有隐藏仍在运行的网页标签页的接口；无头后台页面也无法可靠运行这个登录后的用量页，因此不能做到完全不显示该标签。
3. 约每 30 秒尝试刷新这个专用页并读取其 DOM 中明确标注的额度。首次读取需要等待页面加载；成功后通过本地存储同步至聊天页，无需手动保持用量页在前台。点击角色也会请求尽快更新，正在进行的读取不会重叠启动。
4. 首次请检查后台页已登录，且为你想查看的账号、工作区。后台页读数作为独立数据源，不能视为其他聊天账号的额度；身份无法自动核对时，角色保持中性状态。
5. 关闭该后台标签页会关闭自动更新；关闭开关会停止任务，且仅关闭仍停留在用量地址的非活动专用标签页。用户自己打开的其他页面不受影响。

如果你正在前台查看该专用页，扩展不会定时刷新它。如果能确认你将专用页导航到其他 ChatGPT 页面，扩展会放弃对它的控制，在下次轮询时创建新的专用页。跳转登录页或无法读取目标地址时会暂停，避免反复新建标签页。清除本地用量数据也会停止后台更新，防止刚清除的记录立即被重新写入。

这属于**定期读取，不是实时推送**。浏览器休眠、后台节流、登录失效、网络错误或官方页面不在后台加载时都可能延迟/阻断更新。一次读取等待最多约 45 秒；失败后保留原值和原采集时间，显示待更新，弹窗提示检查后台页。定时任务用 `chrome.alarms`，进程状态用 `chrome.storage.session`，快照用 `chrome.storage.local`，不依赖永不休眠的 Service Worker。

F12 的“网页源码”是调试工具视图，不会比内容脚本读取页面 DOM 更快；ChatGPT 由网页脚本动态显示的用量也不一定出现在原始 HTML 中。扩展直接读取已加载用量区域的 DOM，v0.4.5 将内容脚本提前到 `document_end` 并缩短用量区域变化后的扫描等待时间，不增加 `debugger` 或请求拦截权限。

权限增加了 `alarms`；没有增加 Cookie、请求拦截、浏览历史、全网站访问或 `tabs` 权限。导航和读取使用浏览器已有的登录会话，扩展不提取 Cookie/令牌，不调用未公开额度 API。

### 网页没有显示角色

1. 在 ChatGPT 页面点击扩展工具栏中的“GPT 小伙伴”。
2. 如果弹窗显示“未连接当前页面”，打开 `edge://extensions`，进入本扩展的“详细信息”。
3. 在“站点访问权限”中允许扩展访问 `chatgpt.com`。
4. 回到 `https://chatgpt.com/`，进行一次完整刷新，再次打开弹窗。
5. 弹窗显示“已连接当前页面”后，点击“恢复显示挂件”。

如果主样式文件意外加载失败，v0.1.1 会启用内置备用样式，不再让整个挂件无提示地消失。

## 已完成

- 仅匹配 `chatgpt.com`，权限为 `storage`、`alarms` 和该站点范围。
- 原生 JavaScript、HTML、CSS，无构建步骤、无运行依赖。
- Shadow DOM 样式隔离；深色模式可读；尊重 `prefers-reduced-motion`。
- 保留角色和完整气泡，网页版 PNG 的外部背景透明，气泡固定文字已清空；动态文字由 HTML 安全写入气泡。
- 静态素材只做整体呼吸/浮动，不宣称具有眨眼、闭眼或表情动画。后续可以添加独立状态素材，而不修改当前角色设计。
- 左键切换两种额度、点击压扁动画、四边吸附与左右镜像、窗口缩放约束、位置记忆、大小调整、动画开关、隐藏和恢复、键盘焦点提示。窗口比挂件小时，显示比例会临时缩小以保持可见。
- 角色右键菜单；菜单只覆盖角色交互区，其余网页仍使用原生右键菜单。
- 独立解析层、状态层、存储协调层和 UI 层。
- 15 分钟缓存新鲜度、恢复时间过期保护、5 小时与周窗口独立记录、按采集时间防止旧写入覆盖新快照。
- SPA 路由检测、单例保护、防抖观察器和清理逻辑，避免重复挂件、重复监听和遗留观察器。
- 不读取 Cookie、访问令牌或聊天正文，不保存完整聊天 URL；不调用 OpenAI API 或未公开接口；不发送测试消息；不从进度条宽度推算数据。

`assets/source/character-original.png` 保存原始参考版本，不在运行时加载；`assets/character-web.png` 是清空气泡文字并去除外部背景后的运行素材。扩展不会显示原图中的固定文字。

## 用量解析和真实性边界

生产模式没有模拟数据，也没有演示开关。解析器检查当前可见的以下语义容器：

- `role="dialog"`
- `aria-modal="true"`
- `role="alert"`
- `https://chatgpt.com/settings/usage?tab=overview` 页面中 `main` 区域内的独立额度项目

候选容器还必须含有明确的中英文用量/限制语义。聊天消息区、代码块、引用、模板、`aria-hidden`、`hidden` 和 `inert` 内容会被排除。生产模式仅保留卡片标题或卡片内部明确标识为“5 小时”或“周”的额度，接受明确标注的“剩余/remaining/left”“已用/used”“重置/reset”“恢复/available again”和已达到限制提示。卡片内的“4 小时 45 分钟后重置”“5 天 1 小时后重置”会以采集时刻为起点换算为近似剩余时长；后台每次读取只使用本次页面的时间，不从上一身份继承相对时间。泛用标题下的两个窗口会取得不同的缓存标识，不会互相覆盖。另在可见的“使用限额重置”局部区域内读取“可用 X”；该区域的到期时间不作为额度恢复时间，也不把“可用 X”当成额度余额。“重置：剩余 X%”不被误认为时间。不同窗口使用 `scope + bucketId` 分开保存，不相加、不平均。

本开发环境没有已登录的真实 ChatGPT 用量面板，因此当前状态是：**真实账号页面适配待验证**。`/settings/usage?tab=overview` 适配器支持样例中的“68% left”“35% used”及相应中文顺序，按卡片分别记录 5 小时和周窗口。根据用户提供的页面截图，v0.4.2 增加了“使用限额重置 / 可用 1”结构的独立测试样例；测试通过并不代表真实 DOM 已验证。解析器只遍历该路由可见的 `main` 区域和局部容器，不扫描整个 `document.body.innerText`。页面结构变化后，应在 `parser.js` 的 `blocksFromUsageOverview()`、`usageLimitResetRegion()` 和 `quotaKindForLabel()` 中调整适配器。

普通页面在同一文档内切换路由或关闭用量面板时保留历史读数，不再清空；历史快照不驱动角色状态。用户关闭后台更新时，新文档不会自动恢复另一未知身份的本地记录。后台更新开启后，聊天页可以显示专用后台页的独立快照；每轮替换完整项目集，不混合前一页/前一工作区的窗口。后台页所属账号/工作区无法自动核实时，其读数不驱动当前聊天的角色额度状态。

后台消息核对专用标签页 ID、文档 ID、读取批次和用量路由，旧页面回传不能覆盖新一轮结果。标签页 ID 保存在会话存储中，重启浏览器不会误用上次会话的标签页。源头暂不可见时保留历史快照及原时间；普通 DOM 无关变化不会无限延长缓存有效期。

## 验证结果

自动测试使用独立的 JSON 样例，不会进入生产扩展：

- “剩余 35%”得到 35%。
- “已用 35%”得到剩余 65%。
- overview 页面“68% left”得到剩余 68%，“35% used”得到剩余 65%。
- 只有恢复时间时百分比为 `null`。
- 无候选数据时返回空结果。
- 聊天消息容器中的“剩余 35%”被排除。
- 5 小时与周额度分别记录，左键可切换；“使用限额重置”区域的可用次数仅以“限额重置次数”显示在周额度页。
- 截图结构的“可用 1”与“可用 0”均能读取，隐藏的旧区域被忽略；该区域到期时间不冒充额度恢复时间。
- “重置：剩余 35%”不显示为重置时间；只有充值卡次数时，周额度余额仍未知。
- 完整日期和 GMT 时区可生成倒计时；页面给出的相对恢复时长直接显示原文。只有“18:30”或缺少年份时不猜测，保留原始恢复文字。倒计时每分钟刷新，旧快照和已过恢复时间不继续倒数。
- 截图形式的两条相对恢复时间分别归属 5 小时与周卡片；固定后台标签页、气泡无内部滚动及长文字自适应经过独立浏览器样例检查。
- 左键切换会触发当前页重读与后台更新请求；升级后自动启动后台读取，用户主动关闭后不会被下一次页面启动重新开启。
- 拖动至左、右、上、下边缘会吸附；左侧镜像后图片朝向改变但文字仍正向；窗口缩放、缩放挂件和刷新后仍沿已保存的边缘定位。
- 超过 15 分钟标记为过期，不再驱动角色百分比状态。
- 超过已知恢复时间标记为待更新，不自动填充 100%。
- 后台拒绝用旧时间戳覆盖新快照。
- 后台专用页启动、单例、休眠恢复、旧文档回传隔离、失败保留、用户主动查看/导航保护、关闭/清除停止，以及多窗口完整集替换。
- 页面切换保留历史读数；重复 DOM 扫描不延长原采集时间。

运行测试：

```bash
npm test
```

测试样例通过只证明解析和状态规则符合预期，不等同于真实 ChatGPT 页面验证。真实验证仍需在已登录、能打开官方用量面板或看到官方限制提示的 Edge 页面中完成。

独立 Chromium 测试页还覆盖后台源页面变更 → 协调器存储 → 聊天页气泡更新、仅文本节点变化触发重读、路由切换保留、过期/清除，以及精简 UI、压扁弹回、菜单、缩放边界和隐藏。`node tests/browser-check.cjs` 运行该检查，需要本机有 Playwright 包和 Chromium（可用 `CHROMIUM_PATH` 指定可执行文件）。模拟浏览器 API 和页面样例验证不等同于真实账号验证。

云环境中的 Chromium 被管理员策略禁止加载解压缩扩展，因此真实 Edge、真实登录会话以及 ChatGPT 在后台是否按预期加载用量页面仍待验证。后台功能若一直显示“未识别额度”，需先检查专用页的实际 DOM，不能宣称定期读取成功。

## 页面结构变化时如何维护

解析相关修改集中在 `parser.js`：

1. 先在真实页面中确认容器确实属于官方用量面板或限制提示，并记录其语义角色、可访问名称和稳定结构。
2. 在 `blocksFromDocument()` 增加尽可能窄的适配规则；不要改成扫描 `document.body.innerText`。
3. 保持聊天区、代码块、引用和隐藏内容的排除规则。
4. 将去除个人信息后的结构化输入加入 `tests/fixtures/`。每个额度窗口都给出独立 `scope` 和 `bucketId`。
5. 在 `tests/parser.test.js` 增加期望值，执行 `npm test`。
6. 在真实页面人工核对来源、数值、恢复文字、采集时间、多窗口切换和路由切换，再把对应场景记录为真实验证通过。

不要把整页文字、聊天次数、回答长度、Token 推算、进度条宽度或 API 组织用量作为 ChatGPT 订阅额度来源。

## 文件说明

- `manifest.json`：MV3 配置、最小权限和脚本加载顺序。
- `content.js`：页面生命周期、路由变化、观察器和重新扫描。
- `parser.js`：严格候选识别与用量归一化。
- `state.js`：新鲜度、恢复时间保护、角色状态和本地文案。
- `widget.js` / `styles.css`：Shadow DOM 挂件、拖动、气泡和右键菜单。
- `background.js`：统一存储更新和旧写入保护。
- `reader.js`：专用后台用量页、定时唤醒、超时/停止和文档批次校验。
- `popup.html` / `popup.js`：工具栏设置与恢复显示入口。
- `assets/`：原始参考、网页运行素材和角色头像图标。
- `tests/fixtures/`：只供自动测试使用的结构化样例。
