# GPT 小伙伴

“GPT 小伙伴”是一个无需构建、可直接加载到 Microsoft Edge 的 Manifest V3 扩展。它只在 `https://chatgpt.com/*` 运行，通过 Shadow DOM 注入角色挂件，并且只尝试读取当前页面中实际可见、具有明确语义的用量对话框或限制提示。

## 安装

1. 解压 `gpt-buddy-edge.zip`。
2. 在 Microsoft Edge 地址栏打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择解压后、直接包含 `manifest.json` 的文件夹。
6. 打开或刷新 ChatGPT 页面，然后查看页面右下角的挂件。

也可以直接选择本源码目录进行开发加载。修改脚本后，在扩展管理页点击“重新加载”，再刷新 ChatGPT 页面。

## 使用

- 点击角色：展开或收起气泡详情。
- 拖动角色：移动挂件；位置会保存在 `chrome.storage.local`。
- 右键角色：打开挂件菜单。菜单包含重新读取、缩放、动画开关、隐藏和清除本地用量数据。
- 气泡中的“重新读取”：只扫描当前可见的候选用量区域，不点击按钮、不打开设置、不切换模型，也不刷新页面。
- 工具栏图标：挂件隐藏后可从弹窗恢复显示，也可调整大小、切换动画或清除快照。

如果页面没有可验证的读数，挂件会显示“打开用量面板，让我看看”。未知、过期或恢复时间已过的数据均使用中性状态，不会伪装成额度耗尽或自动恢复为 100%。

## 已完成

- 仅匹配 `chatgpt.com`，权限只有 `storage` 和该站点范围。
- 原生 JavaScript、HTML、CSS，无构建步骤、无运行依赖。
- Shadow DOM 样式隔离；深色模式可读；尊重 `prefers-reduced-motion`。
- 保留角色和完整气泡，网页版 PNG 的外部背景透明，气泡固定文字已清空；动态文字由 HTML 安全写入气泡。
- 静态素材只做整体呼吸/浮动，不宣称具有眨眼、闭眼或表情动画。后续可以添加独立状态素材，而不修改当前角色设计。
- 点击、拖动、窗口缩放约束、位置记忆、大小调整、动画开关、隐藏和恢复、键盘焦点提示。
- 角色右键菜单；菜单只覆盖角色交互区，其余网页仍使用原生右键菜单。
- 独立解析层、状态层、存储协调层和 UI 层。
- 15 分钟缓存新鲜度、恢复时间过期保护、多窗口独立记录、按采集时间防止旧写入覆盖新快照。
- SPA 路由检测、单例保护、防抖观察器和清理逻辑，避免重复挂件、重复监听和遗留观察器。
- 不读取 Cookie、访问令牌、聊天正文或完整聊天 URL；不调用 OpenAI API 或未公开接口；不发送测试消息；不从进度条宽度推算数据。

`assets/source/character-original.png` 保存原始参考版本，不在运行时加载；`assets/character-web.png` 是清空气泡文字并去除外部背景后的运行素材。扩展不会显示原图中的固定文字。

## 用量解析和真实性边界

生产模式没有模拟数据，也没有演示开关。解析器只检查当前可见的以下语义容器：

- `role="dialog"`
- `aria-modal="true"`
- `role="alert"`

候选容器还必须含有明确的中英文用量/限制语义。聊天消息区、代码块、引用、模板、`aria-hidden`、`hidden` 和 `inert` 内容会被排除。解析器只接受明确标注的“剩余/remaining/left”“已用/used”“重置/reset”“恢复/available again”和已达到限制提示。不同项目使用 `scope + bucketId` 分开保存，不相加、不平均。

本开发环境没有已登录的真实 ChatGPT 用量面板，因此当前状态是：**真实页面适配待验证**。代码没有编造 ChatGPT 私有 DOM 选择器，也不声称已在真实用量页读取成功。ChatGPT 页面结构变化或实际面板结构经过人工核对后，应在 `parser.js` 的候选容器提取层中增加经过验证的适配器，并继续复用同一严格的数据归一化逻辑。

如果无法确认账号或工作区身份，扩展不会在新页面会话中把本地历史快照当作当前读数。快照仍会保存供清除和写入协调使用，但当前角色状态只采用本页本次实际扫描到的读数。这避免了切换账号或工作区后误用上一身份数据。设置通过 `chrome.storage.local` 在标签页之间同步；后台统一按 `capturedAt` 合并快照，旧标签页写入不会覆盖较新记录。

## 验证结果

自动测试使用独立的 JSON 样例，不会进入生产扩展：

- “剩余 35%”得到 35%。
- “已用 35%”得到剩余 65%。
- 只有恢复时间时百分比为 `null`。
- 无候选数据时返回空结果。
- 聊天消息容器中的“剩余 35%”被排除。
- 短周期与周额度分别记录。
- 超过 15 分钟标记为过期，不再驱动角色百分比状态。
- 超过已知恢复时间标记为待更新，不自动填充 100%。
- 后台拒绝用旧时间戳覆盖新快照。

运行测试：

```bash
npm test
```

测试样例通过只证明解析和状态规则符合预期，不等同于真实 ChatGPT 页面验证。真实验证仍需在已登录、能打开官方用量面板或看到官方限制提示的 Edge 页面中完成。

另外使用独立 Chromium 测试页验证了以下 UI 行为：挂件单例、气泡文字布局、多额度下拉框、点击展开详情、角色右键菜单、拖动以及窗口缩小后的可见区域约束；页面脚本错误为 0。工具栏弹窗也完成了模拟扩展 API 的交互检查。云环境中的 Chromium 被管理员策略禁止加载解压缩扩展，因此没有把这些独立 UI 检查描述成真实 Edge 扩展验证。

## 页面结构变化时如何维护

解析相关修改集中在 `parser.js`：

1. 先在真实页面中确认容器确实属于官方用量面板或限制提示，并记录其语义角色、可访问名称和稳定结构。
2. 在 `blocksFromDocument()` 增加尽可能窄的适配规则；不要改成扫描 `document.body.innerText`。
3. 保持聊天区、代码块、引用和隐藏内容的排除规则。
4. 将去除个人信息后的结构化输入加入 `tests/fixtures/`。每个额度窗口都给出独立 `scope` 和 `bucketId`。
5. 在 `tests/parser.test.js` 增加期望值，执行 `npm test`。
6. 在真实页面人工核对来源、数值、恢复文字、采集时间、多窗口切换和路由切换，再把对应场景记录为真实验证通过。

不要把整页文字、聊天次数、回答长度、Token 推算、进度条宽度或 API 组织用量作为 ChatGPT 订阅额度来源。

## 文件说明

- `manifest.json`：MV3 配置、最小权限和脚本加载顺序。
- `content.js`：页面生命周期、路由变化、观察器和重新扫描。
- `parser.js`：严格候选识别与用量归一化。
- `state.js`：新鲜度、恢复时间保护、角色状态和本地文案。
- `widget.js` / `styles.css`：Shadow DOM 挂件、拖动、气泡和右键菜单。
- `background.js`：统一存储更新和旧写入保护。
- `popup.html` / `popup.js`：工具栏设置与恢复显示入口。
- `assets/`：原始参考、网页运行素材和角色头像图标。
- `tests/fixtures/`：只供自动测试使用的结构化样例。
